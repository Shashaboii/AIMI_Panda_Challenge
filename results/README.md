# Results artefacts

* `val_df_effnet.csv` — EfficientNet-B0 validation predictions (image_id, data_provider,
  true_isup, pred_isup) on the fold-0 held-out set, generated by
  `notebooks/03b_dump_effnet_val_predictions.ipynb`.
* `val_df_uni.csv` — UNI + MIL validation predictions, same format, from
  `notebooks/06_uni_train_mil_head.ipynb`.

Both feed the CNN-vs-UNI error comparison in
`notebooks/02_eda_data_understanding.ipynb` (worst errors, label-noise overlap,
missed-cancer vs false-alarm counts).
